# Curios API — инструкции для AI-агентов

Порт Curios API на Fabric 1.21.1. Только Fabric. Второй загрузчик не добавлять. `mod_id` — `curios`. Пакет своего кода — `com.curios.mod`. Публичный API остаётся в `top.theillusivec4.curios.api`, чтобы чужой код находил те же имена.

Лицензия исходника — LGPL-3.0-or-later. На MPL-2.0 не перелицензировать. На Modrinth и на Mikchan CDN не публиковать. Jar лежит в GitHub Release `minecraft-1.21.1-fabric`. `.github/workflows/sync-to-gitlab.yml` зеркалит репозиторий и этот релиз в `naragan/curios-api-port-mod`: на GitLab те же название и текст, а файлы — ссылки на скачивание GitHub. Второй jar не заливается. Это не пакет `modpacks-curios`: тот остаётся пропатченным curiosfabric и в сборку не входит. Сборка Kidou берёт GitHub Release через `type: github`. У Kidou 1.1.4 нет типа `gitlab`.

`org.gradle.jvmargs` остаётся `-Xmx2G`. Wrapper не добавлять. Сборка — Gradle 8.11 и JDK 21.

## Поиск готового

Прежде чем писать своё, портировать или декомпилировать, найди готовый мод, порт или форк. Веб-поиск (Google, Perplexity) малоизвестные репозитории GitHub не видит: репозиторий без звёзд и без ссылки с уже проиндексированной страницы в их индекс не попадает. Ищи каталог GitHub. Перед поиском прочитай https://github.com/aaddrick/gh-cli-search/blob/main/skills/gh-search-repos/SKILL.md и для исходников https://github.com/aaddrick/gh-cli-search/blob/main/skills/gh-search-code/SKILL.md. Нижний порог звёзд не ставь: примеры `stars:>N` в скилле применяй только если владелец просил известные проекты. Скилл https://github.com/py-sit/github-search-skill отбрасывает репозитории без лицензии, без свежих коммитов и учебные, поэтому для порта и малоизвестного мода его не открывай. Сделай несколько запросов: `gh search repos` по имени, `--match readme` и `gh search code` по mod id; для порта добавь `--include-forks true` и список форков исходного репозитория. Дефис в имени совпадает со словами запроса. Минус в начале квалификатора — исключение: такой запрос отделяй `--`, в PowerShell ещё `gh --%`. Пустое описание, ноль звёзд и пустые topics результат не отменяют. Опубликованные моды дополнительно смотри в поиске Modrinth: исходник порта часто есть только на GitHub. Свою реализацию не начинай, пока этот поиск не сделан.

## Локальные инструменты

Kidou — локальный инструмент этой мастерской. Искать сведения о нём в интернете бесполезно: публичной документации нет. Источник — спецификация в `D:\DATA\soft\code\projects\minecraft\modpacks\Kidou-1.1.8-release.jar` и `D:\DATA\soft\code\projects\minecraft\modpacks\AGENTS.md`.

Миксины пишутся на именах Mojang. Сборка ставит `loom.mixin.useLegacyMixinAp = false`: процессор аннотаций Java Kotlin-миксинов не видит, а tiny-remapper переименовывает цели прямо в `remapJar`. После правки миксина проверь, что в классе из `build/libs` цель стала `method_…` или `field_…`. До 1.0.5 миксины целились в промежуточные имена с `remap = false`, и `runClient` падал ещё до меню: в dev-клиенте `InventoryScreenMixin` не находил `method_25426`.

Модель игрока рисует надетые предметы из вложения `curios:inventory`. Серверный reload по-прежнему единственный источник датапака на выделенном сервере. Клиент при старте читает те же файлы из jar модов, а `TrinketsApi` добавляет к этому списку уже надетые предметы из вложения: иначе Sophisticated Backpacks на выделенном клиенте не находит рюкзак и сразу закрывает экран. Окно curios содержит ванильные слоты брони и левой руки. Shift-клик по корзине в креативе очищает и слоты curios.

## Проверка мода и сборки

Работа над модом или сборкой заканчивается только после тестов, проверки запуском локального сервера и локального клиента. Сборка jar без этого не считается готовой.

Из этого каталога: `gradle test`, затем `gradle runClient` до главного меню, затем `gradle runServer` до строки `Done`. Окно и сервер после этого закрыть.

## Craft Anything

[Craft Anything](https://github.com/storytold/craft-anything) — ранняя альфа. Она смотрит, как устроена чужая программа, сайт или игра, и только по отдельной просьбе владельца собирает свою версию. Агенту достаточно `craft-anything-cli`; те же средства отдаёт `craft-anything-cli mcp`. Если команды нет, в середине задачи её не ставить и чужой файл вместо неё не вскрывать.

По умолчанию чистая комната: исходник, файлы и код страницы закрыты. Наружу попадает только видимое: снимок, текст, размеры, цвета, шрифты, открытые меню. Deep включается флагом `--deep` и читает код и файлы своими декодерами, а при установленной Ghidra ещё и ей. Это не песочница системы и не обход защиты, входа или античита. Цель берут только ту, которую владелец имеет право изучать. Логотипы, фотографии и чужой текст в репозиторий не копируют. Запись инструмента — свидетельство с уверенностью и оговорками, не замена нашему коду. Новая сборка по умолчанию уходит в `Documents/Craft Anything`. Править этот репозиторий ею можно только когда владелец просил сборку, с `--project-folder` на каталог репозитория и `--existing edit`. Установка зависимостей выполняет код пакетов; согласие «always allow» для `npm` не давать. Сверка сайта на трёх ширинах уже работает, сверка поведения программ и игр ещё неполная. Статус — `docs/STATUS.md` в том репозитории.

Порт Curios уже найден: Fabric 1.21.1, публичный API остаётся в `top.theillusivec4.curios.api`, лицензия LGPL-3.0-or-later. Инструмент не ищет вторую реализацию и не переименовывает API. Deep выключен. Чистая комната уместна, только если владелец просит сверить видимое окно слотов; правки пишут в этот исходник. На Modrinth и CDN порт по-прежнему не публикуют.
